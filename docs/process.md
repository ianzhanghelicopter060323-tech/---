| 模块 | 主要工作 | 输出 |
|---|---|---|
| 选手名单采集 | 请求节目百科页面，提取参赛选手姓名和个人百科链接 | `stars.json` |
| 个人信息采集 | 逐个访问个人页面，提取民族、星座、血型、身高、体重、出生年份 | `stars_info.json` |
| 图片下载 | 提取图片链接，按选手姓名建立文件夹并下载 | `pics/姓名/` |
| 数据清洗 | 去除换行、单位和无效内容，将身高、体重等转换为数值 | 可用于统计的数据 |
| 统计与可视化 | 统计出生年份、体重区间、身高区间的人数 | 柱状图和饼图 |
